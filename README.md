# 12-Zodiac Interactive Dashboard

An interactive, client-only dashboard to explore the 12 Chinese zodiac animals with filtering, search, language toggle, and light/dark themes. No backend or external data files required.

## ✨ Features
- **12-card grid** (Rat → Pig) with emoji icons and bilingual names (EN + 中文)
- **Hover tooltips** show each sign’s key trait
- **Slide-in detail panel** (modal) with element, trait, and personality description + subtle glow animation
- **Filters & search**
  - Element dropdown (Metal, Wood, Water, Fire, Earth)
  - Instant search across English and Chinese names, traits, descriptions, and keywords
- **Language toggle**: English ⇄ 中文 updates all UI text dynamically
- **Theme switch**: Light/Dark with smooth transitions; respects OS preference on first load
- **Responsive layout**: 4×3 grid on desktop, single-column scroll on mobile
- **Persistence**: Remembers language, theme, filter, and search via `localStorage`

## 🚀 Run locally
1. Open `index.html` directly in your browser, **or**
2. Serve the folder with any static server (recommended for consistent behavior):
   - PowerShell (if Python is available):
     ```pwsh
     python -m http.server 8000
     ```
     Then visit http://localhost:8000

No build step is required.

### ✅ Headless check (optional)
```pwsh
npm install
npm test
```
This launches a minimal static server, loads the page in Puppeteer, and asserts 12 cards render.

## 🗂 Structure
- `index.html` — markup and containers for controls, grid, and detail panel
- `style.css` — theming, layout, animations, responsive rules
- `script.js` — autogenerated zodiac dataset, UI rendering, filtering, state persistence

## 🔧 Notes
- Preferences are stored under the key `zodiacDashboardPrefs` in `localStorage`.
- Elements are displayed with translated labels (e.g., 水 for Water when in 中文).
- Press **Esc** or click outside the panel to close the detail view.
